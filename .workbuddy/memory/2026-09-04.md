## 项目要点（供后续复用）

- fetch_typhoon.py 的抓取策略是 **活跃台风优先 + 最近 2 个历史台风**（见 main() 中 `targets = active if active else metas[-3:]`），
  因此 `totalCount` 通常远小于 `yearCount`。文件体积随活跃台风数量波动属正常，不是丢数据。
- JSON 顶层字段：updateTime / year / source / activeCount / totalCount / yearCount / provinces(14 个沿海省级) / typhoons。
- 每台风字段：num, cnName, enName, status(start|stop), active, startTime, endTime, latest, peak, maxWind, minPressure, landfall, impact, pointCount, points, forecast。
- 台风中心定位：impact.current 为精确命中省份，impact.near 为 4 度内临近省份，两者皆 null 表示暂不影响我国。
